# Archive portability layout checks

These development screenshots use synthetic mail fixtures and the production fonts. The widget implementation, localized strings and visual test source are byte-identical to the frozen acceptance candidate; `provenance.json` records their Git identities and image hashes. The final acceptance run executes the same visual tests without enabling optional PNG output. These are not live-mailbox, native file-picker or installed macOS screenshots.

The set covers English desktop controls, Arabic narrow-screen controls, both export confirmations and both destination reports.
