## Reproduce

Use the pinned runtime in [flutter-release.json](flutter-release.json), restore
the recorded workspace lockfile if exact dependency versions are needed, and
resolve workspace dependencies before invoking the integration runner:

```sh
export CI=true
flutter pub get
python3 tools/proofing/verify_integration.py
```

The official Linux Flutter archive was SHA-256 verified before extraction:
`baf7dcc5a3dbba60fe863bf493a6cf203195621f7786eaa5a1bba02cd0d87dd2`.
[flutter-archive-sha256.log](flutter-archive-sha256.log) preserves that check.
Use a writable temporary directory and sufficient disk space. The first
combined attempt at `5415584` encountered a full temporary filesystem and
strict analyzer diagnostics; its [failure record](../integration-attempt-5415584/receipt.json)
is retained. The final run follows removal of disposable download/temp files,
analyzer corrections and a sequential test configuration.
